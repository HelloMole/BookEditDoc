快速部署 ​

此篇内容仅针对需要二次开发部署的程序员，如果你只需要学习如何使用此工具，请前往快速上手

首先前往Github克隆此项目到本地。

此项目基于Vue3构建，如果需要扩展开发，请参考Vue开发文档。

此项目使用的Nodejs版本v18.20.8，请先安装node环境，如果遇到报错，请检查node版本是否匹配。

此项目针对Cocos Creator2.4.10进行开发，如果需要使用3.0以上版本，理论上也可适配，但可能需要手动修改部分Api

下载好项目后，进入项目目录，执行操作

cmd
npm install

安装依赖成功后，启动服务

cmd
npm run dev

如果需要构建网页部署

cmd
npm run buildEdit

构建成功后生成的网页在dist文件夹下，可以手动部署（把dist目录下的文件上传到oss中）

TIP

构建成功后还需要手动将项目下的otplib文件夹和spine-runtimes文件夹拷贝到dist/assets目录下，这样网页才能正常打开，否则会报错

如果已经有使用阿里云的oss容器，可配置ossConfig和upToOss.mjs中的ossBaseUrl(页面上传的路径) 需要下载ossutil并放置在目录下，如果是mac系统，ossutil的名称应该是ossutilmac64，如果是windows系统，ossutil的名称应该是ossutil64.exe

cmd
npm run deployEdit
