输出节点 ​

提示 ​

文字提示 ​

弹出文字提示信息，显示给用户。

输入：

  • msg：要显示的提示内容（可通过属性设置）
  • 显示：触发显示提示的事件

属性：

  • 内容：提示文字内容

说明： 触发后会以弹窗形式显示提示信息。

确认框 ​

弹出确认对话框，用户可以选择确认或取消。

输入：

  • msg：要显示的确认内容（可通过属性设置）
  • 显示：触发显示确认框的事件

输出：

  • 确认：用户点击确认时触发
  • 取消：用户点击取消时触发

属性：

  • Text：确认框的提示文字

说明： 触发后会显示确认对话框，根据用户的选择触发不同的输出事件。

触摸提示 ​

播放一个触摸提示的动画，引导用户进行交互。

输入：

  • 物体：要显示提示的物体节点（通常是手指动画）
  • 显示：触发显示提示的事件
  • 关闭：触发关闭提示的事件

输出：

  • 结束：提示动画结束时触发

属性：

  • 类型：选择提示动画类型
    • 单次点击：播放一次点击动画
    • 快速点击：播放快速点击动画
    • 拖拽：从当前位置拖拽到目标位置
    • 上下滑动：上下滑动动画
    • 左右滑动：左右滑动动画
    • 转圈：转圈动画
    • 长按：长按动画
  • 大小：提示动画的缩放大小
  • 拖拽终点-x/y：拖拽动画的目标位置（仅拖拽类型）
  • 长度或半径：滑动或转圈的距离/半径
  • 速度：动画的移动速度

说明：

  • 可以点击"创建触摸动画"自动创建手指动画物体
  • 可以点击"预览效果"预览提示动画
  • 节点启动时默认关闭提示

输出控制台 ​

将内容打印到浏览器控制台，用于调试。

输入：

  • msg：要打印的内容（可通过属性设置）
  • log：以log级别打印
  • warn：以warn级别打印
  • error：以error级别打印

属性：

  • msg：要打印的内容

说明：

  • 可以通过不同的输入接口选择不同的日志级别
  • 输入值会显示在输入接口的标签上

游戏控制 ​

重新开始 ​

重新开始游戏流程，重置当前分镜。

输入：

  • 重启：触发重新开始的事件

说明： 触发后会停止当前蓝图，然后重新启动。

切换页面 ​

切换到新的页面（分镜）。

输入：

  • 切换：触发切换页面的事件

属性：

  • 页码：目标页面的页码（从1开始）
  • 页面名称：目标页面的名称

说明： 触发后会停止当前蓝图，然后加载并启动指定的页面。

页面结束 ​

标记当前页面阅读结束。

输入：

  • 结束：触发页面结束的事件

说明： 触发后会通知应用当前页面已结束，通常用于绘本翻页逻辑。

通知绘本操作 ​

操作绘本相关事件，与绘本应用交互。

输入：

  • 触发：触发操作的事件
  • param：附加的参数信息

属性：

  • 事件：选择要触发的事件类型
    • 隐藏底部字幕：隐藏页面底部的字幕
  • 附加信息：附加的参数信息

说明： 用于与绘本应用进行交互，触发应用层面的操作。

时间控制 ​

停止时间 ​

暂停或恢复游戏时间，暂停所有时间相关的动画和逻辑。

输入：

  • 停止：触发暂停的事件
  • 恢复：触发恢复的事件

说明：

  • 停止：暂停当前蓝图，所有时间相关的逻辑都会暂停
  • 恢复：恢复当前蓝图，继续执行逻辑

时间缩放 ​

加速或减慢时间效果，影响所有时间相关的动画和逻辑。

输入：

  • scale：时间缩放倍数（可通过属性设置）
  • 修改：触发修改时间缩放的事件

属性：

  • 缩放倍数：时间缩放的比例（0-10，1为正常速度）

说明：

  • 缩放倍数大于1时，时间变快
  • 缩放倍数小于1时，时间变慢
  • 会影响所有动画、延迟、间隔等时间相关的节点

脚本组件 ​

自定义脚本组件，用于扩展功能。

说明： 可以通过脚本组件实现自定义的逻辑和功能。

屏蔽触摸 ​

屏蔽触摸事件，防止用户误操作。

输入：

  • 开启：触发开启屏蔽的事件
  • 关闭：触发关闭屏蔽的事件

说明：

  • 开启后，所有触摸事件都会被屏蔽
  • 关闭后，恢复正常触摸响应
  • 节点停止时会自动关闭屏蔽

文本转音频 ​

将文本转换为音频文件，需要开通讯飞文本转音频接口服务。

属性：

  • 文本：要转换的文本内容
  • 命名：生成的音频文件名称
  • 音色：选择语音音色
    • 聆飞逸、聆小璇、聆小玥、聆玉昭、聆玉言、动漫少女
  • 语速：语音播放速度（0-100）
  • 音量：语音音量大小（0-100）
  • 语调：语音语调高低（0-100）
  • 背景音：是否添加背景音

说明：

  • 点击"生成音频"按钮后，会调用讯飞接口生成音频
  • 生成的音频会自动上传到云端
  • 需要先在系统设置中配置讯飞的AppID、ApiSecret和ApiKey
  • 此功能需要开通讯飞文本转音频接口服务

振动 ​

调用设备振动功能，提供触觉反馈。

输入：

  • 震动：触发振动的事件

属性：

  • 振动强度：振动的强度（0-1）
    • 小于0.5：短振动
    • 大于等于0.5：长振动

说明： 仅在支持振动的设备上有效。

自动点击 ​

自动执行录制好的点击操作，用于自动化测试或演示。

属性：

  • 是否激活：是否启用自动点击功能

说明：

  • 需要在"录制操作"模式下运行蓝图并录制点击操作
  • 启用后，运行蓝图时会自动执行录制好的点击序列
  • 点击操作会按照录制时的时间顺序执行

保存自定义数据 ​

保存自定义数据到本地或云端。

说明： 用于保存游戏进度、用户数据等自定义信息。
